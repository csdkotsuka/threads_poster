# Threads投稿アシスタント（大人の自立と暮らしのつぶやき）

Threads（スレッズ）のアカウント運用をスムーズに行うための、**スマホ特化型・投稿支援Webアプリ**です。  
厳選された150本の投稿ストックを、ワンタップでコピーしてThreadsへ直接投稿・進捗管理できます。

---

## 🌟 主な機能

1. **ワンタップ・コピー**
   - 投稿カードをタップするだけで、本文とハッシュタグが瞬時にクリップボードへコピーされます。
2. **Threadsへの直接ジャンプ**
   - 「Threadsで投稿」ボタンを押すと、投稿作成画面が直接立ち上がります。
3. **投稿進捗チェック（端末内自動保存）**
   - 「投稿済み」にチェックを入れると、進捗バー（例: `12 / 150 完了`）が更新されます。
   - ブラウザ（LocalStorage）に保存されるため、ページを閉じても記録が消えません。
4. **カテゴリー絞り込み & 状態フィルター**
   - 「未投稿のみ」「完了済み」「カテゴリー別」の表示切り替えが可能です。
5. **固定ヘッダー**
   - スクロールしても上部に常時固定され、アカウントプロフィール（`@nakama_no_drawer`）へいつでもアクセスできます。

## 🚀 使い方（GitHub Pagesで自分専用URLを発行する手順）

本リポジトリはHTML単体で動作するため、サーバー不要・完全無料でWebアプリとして公開できます。

1. 本リポジトリの **Settings**（設定）タブを開きます。
2. 左メニューの **Pages** を選択します。
3. **Build and deployment** の項目で、以下を選択して **Save** をクリックします：
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `/(root)`
4. 数分待つと、画面上部に公開URL（例: `https://<あなたのユーザー名>.github.io/<リポジトリ名>/`）が表示されます。
5. そのURLをスマホのブラウザ（Safari や Chrome）で開けば、すぐに利用可能です！

---

## 📱 スマホのホーム画面に追加してアプリ化する（おすすめ！）

Safari（iPhone）や Chrome（Android）のホーム画面追加機能を使うと、本物のスマホアプリのようにワンタップで起動できるようになります。

- **iPhone（Safari）の場合**：
  1. 公開URLをSafariで開く
  2. 画面下部の共有ボタン（四角から上矢印が出ているアイコン）をタップ
  3. **「ホーム画面に追加」** を選択
- **Android（Chrome）の場合**：
  1. 公開URLをChromeで開く
  2. 右上のメニュー（︙）をタップ
  3. **「ホーム画面に追加」** または **「アプリをインストール」** を選択

## 💡 投稿運用のコツ

- **ペース配分**: 1日1〜2本、朝（7〜8時）や夜（20〜22時）のリラックスタイムに投稿するのが効果的です。
- **カテゴリーの循環**: 本アプリのリスト順（Day 1 → Day 2 → ...）に投稿していくだけで、日々の暮らし・心境・働き方の話題が自然なバランスで流れるよう設計されています。
- **交流**: 投稿についたコメントやいいねには、同世代の友達のように自然体で返信するとファンが増えやすくなります。
